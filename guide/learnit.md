# _learnit

Learning mentor for any topic (IT, history, biology, languages…). Remembers progress across sessions.

## Usage

Say e.g. "I want to learn…", "let's get back to learning", "quiz me on…", "export the lessons".

## How it works

1. A conversation about scope and your level; your questions feed into the program.
2. A plan of 3–10 stages, each with a goal ("after this stage you can…").
3. One lesson per stage (file + chat): hook, explanation, examples, pitfalls, sources, exercises.
4. Checks as practice, not exams: contextual questions, hints before answers, three-part feedback.
5. A support plan after repeated difficulty; reviews after 1, 3, 7, 21 days, then every 60.
6. Export a course to a single Markdown file (with a tutor prompt) to share with others.

## Data

Local only, in `~/.claude/learning/` (`INDEX.md`, `profile.md`, one folder per topic). No git, no sync. File names in English, content in the conversation language.
