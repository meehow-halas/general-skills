# Recipient instructions: export template

Paste as the first section of the export, right under the title. Fill in `<COURSE>`, `<N>` (number of stages), `<READY>` (numbers of stages with a finished lesson). Translate into the topic language if different. Do not shorten.

---

## Read this first: what this is and how to use it

### What this is

This is the course "<COURSE>" in a single file. It has <N> stages. Each stage is a lesson to read, exercises, and a short check that the knowledge stuck. Stages <READY> have finished lessons. The rest have a sketch from which an AI assistant will write the lesson when you get to it. The lesson will be fitted to how you're doing.

You need no installation. All you need is this file and any chat with an AI assistant, e.g. Claude, ChatGPT, or Gemini. You can also study alone, without AI.

### Way 1: with an AI assistant (recommended)

1. Open a new conversation with an AI assistant.
2. Paste the **whole** file. At the end is the "Tutor prompt", the instructions for the assistant on how to guide you. Don't remove anything.
3. Add one sentence below, e.g. "I'm starting the course" or, if you're returning, "I'm back, here is my progress card:" and paste the card (see below).
4. The assistant gives you the lesson and waits. Read at your own pace, ask whatever you like. When you're done, write "I've read it".
5. Then you'll get exercises or a few questions, one at a time. It's practice, not an exam: mistakes are fine, and on a mistake you get a hint first.
6. You finish whenever you want. Write "that's all for today".

### Progress card: your memory between conversations

An AI assistant usually doesn't remember earlier conversations. So at the end of each session it will write out a **progress card**: a short block with the stage, what went well, what was hard, what to review, and when.

- **Save it**, e.g. in your notes or at the end of this file.
- **Next session**, paste the file and the card into a new conversation. The assistant will start where you left off, suggest short reviews, and fit the next lessons.
- If the assistant forgets to write the card, say: "write out the progress card".

### Way 2: alone, without AI

For each stage with a finished lesson: read the lesson, do the exercises, answer the "Check yourself" questions, and only then expand the "Answer key". Stages that have only a sketch need an AI assistant. You can also treat them as a list of topics to read up on in the listed sources.

### Good to know

- **The pace is yours.** No deadlines. Reviews from the card are a hint, not an obligation.
- **The quality of lessons written from sketches depends on the assistant.** It's best to use a model with internet access so it can check sources. Claims it hasn't verified should be marked as uncertain.
- **The answer key** is hidden under a collapsible field. The assistant won't reveal it until you ask.
- **Something off?** If the assistant starts writing stiffly or asks questions before the lesson, say: "stick to the tutor prompt at the end of the file".

### Contents of the file

1. These instructions
2. Course goal, audience, plan of stages
3. Stages: finished lessons and sketches
4. Method: how the tutor runs the course and what it is based on
5. Sources
6. Tutor prompt
